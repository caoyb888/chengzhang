## 二、分层架构约定

### 2.1 各层职责边界（详细版）

#### Controller 层

```java
// 职责：参数接收 → 入参校验 → 调用 Service → 返回 Result
// 禁止：业务逻辑、直接操作 Mapper、事务注解

@RestController
@RequestMapping("/api/v1/paper")
@RequiredArgsConstructor
@Slf4j
public class PaperSubmitController {

    private final PaperFlowService paperFlowService;

    @PostMapping("/{paperId}/submit")
    @SaCheckPermission("paper:submit")
    public Result<Void> submit(
            @PathVariable @NotNull Long paperId,
            @RequestBody @Valid PaperSubmitDTO dto) {
        // Controller 只做：1.路径参数/Body 校验  2.调用 Service  3.返回
        paperFlowService.submitNode(paperId, dto);
        return Result.ok(null);
    }
}

// 禁止写法（业务逻辑在 Controller）：
@PostMapping("/{paperId}/submit")
public Result<Void> submit(@PathVariable Long paperId, @RequestBody PaperSubmitDTO dto) {
    Paper paper = paperMapper.selectById(paperId);   // 禁止：直接操作 Mapper
    if (paper.getStatus().equals("REVIEWING")) {     // 禁止：业务判断在 Controller
        return Result.fail(400, "审核中不可提交");
    }
    paper.setStatus("SUBMITTED");
    paperMapper.updateById(paper);                   // 禁止：直接写库
    return Result.ok(null);
}
```

#### Service 层

```java
// 职责：业务规则 → 事务管理 → 跨实体协调 → 事件发布
// 规则：
//   - 接口定义在 service/ 包，实现在 service/impl/ 包
//   - @Transactional 注解只能加在 Service 实现层，禁止加在 Controller
//   - Service 实现之间禁止直接 @Autowired 注入（防止循环依赖 + 层次混乱）
//   - 跨模块调用必须通过 Feign Client 或 MQ

@Service
@RequiredArgsConstructor
@Slf4j
public class PaperFlowServiceImpl implements PaperFlowService {

    private final PaperMapper paperMapper;
    private final BatchFlowConfigMapper configMapper;
    private final RocketMQTemplate rocketMQTemplate;
    private final RedissonClient redissonClient;

    @Override
    @Transactional(rollbackFor = Exception.class)
    public void submitNode(Long paperId, PaperSubmitDTO dto) {
        // 1. 查询论文（带数据权限校验）
        Paper paper = getPaperOrThrow(paperId);

        // 2. 校验时间窗口 + 前置节点
        validateSubmitCondition(paper, dto.getNodeType());

        // 3. 状态变更（同一事务内）
        updateNodeStatus(paperId, dto.getNodeType(), NodeStatus.SUBMITTED);

        // 4. 写提交记录（同一事务内）
        saveSubmitRecord(paperId, dto);

        // 5. 写操作日志（同一事务内）
        saveOperationLog(paperId, "SUBMIT", dto.getNodeType());

        // 6. 发布 MQ 事件（事务提交后才实际发送，使用 RocketMQ 事务消息）
        log.info("[论文提交] paperId={}, nodeType={}, studentId={}",
                paperId, dto.getNodeType(), StpUtil.getLoginIdAsLong());
        rocketMQTemplate.sendMessageInTransaction(
                "thesis-paper-submit",
                MessageBuilder.withPayload(PaperSubmitEvent.of(paperId, dto.getNodeType())).build(),
                null);
    }
}
```

### 2.3 跨服务调用决策树

```
需要调用另一个微服务？
    │
    ├── 需要实时返回结果，且目标服务高可用？
    │       → 使用 Feign Client（同步 HTTP 调用）
    │         Feign 接口定义在 thesis-common 或调用方服务
    │         必须配置 Feign 超时（connectTimeout=3s, readTimeout=5s）
    │         必须配置 Sentinel 熔断（超时率 > 50% 触发熔断 60s）
    │
    ├── 不需要实时结果，或目标服务可能繁忙？
    │       → 使用 RocketMQ 事件驱动（异步解耦）
    │         适用：通知发送、AI 评议、统计更新、日志写入
    │
    └── 需要查询另一个服务的数据，但数据变化频率低？
            → 考虑数据冗余（在本服务表中冗余必要字段）
              并通过 MQ 事件保持最终一致性

// Feign Client 示例
// 定义在 thesis-user 的 feign 包，由 thesis-paper 引用
@FeignClient(
    name = "thesis-user",
    fallbackFactory = UserServiceFallbackFactory.class
)
public interface UserServiceClient {
    @GetMapping("/internal/user/{userId}")
    Result<UserInfoVO> getUserById(@PathVariable Long userId);
}

// 降级工厂（必须实现，不可省略）
@Component
public class UserServiceFallbackFactory implements FallbackFactory<UserServiceClient> {
    @Override
    public UserServiceClient create(Throwable cause) {
        return userId -> {
            log.warn("[Feign 降级] UserService.getUserById, userId={}, cause={}", userId, cause.getMessage());
            return Result.fail(503, "用户服务暂时不可用");
        };
    }
}
```

### 2.4 事务边界规范

```java
// 规则 1：@Transactional 只加在 Service 实现方法上，禁止加在 Controller / Mapper
// 规则 2：必须指定 rollbackFor = Exception.class（默认只回滚 RuntimeException）
// 规则 3：事务内禁止调用外部 HTTP / 发送 MQ（应在事务提交后执行）
// 规则 4：只读操作加 @Transactional(readOnly = true) 优化性能

// 正确：事务提交后发 MQ（使用 Spring 事件 + @TransactionalEventListener）
@Transactional(rollbackFor = Exception.class)
public void submitNode(Long paperId, PaperSubmitDTO dto) {
    // ... 数据库操作 ...

    // 通过 Spring 事件，在事务提交后异步发送 MQ（不会因 MQ 失败导致 DB 回滚）
    applicationEventPublisher.publishEvent(
        new PaperSubmitEvent(this, paperId, dto.getNodeType()));
}

@TransactionalEventListener(phase = TransactionPhase.AFTER_COMMIT)
public void onPaperSubmit(PaperSubmitEvent event) {
    rocketMQTemplate.convertAndSend("thesis-paper-submit", event);
}

// 错误：事务内调用外部 HTTP（Feign/MQ 异常会导致整个事务回滚，且 MQ 消息已发但 DB 回滚）
@Transactional
public void submitNode(...) {
    paperMapper.insert(paper);
    notifyServiceClient.sendNotify(...);  // 错误：事务内调用外部服务
    rocketMQTemplate.send("...", msg);    // 错误：事务内直接发 MQ
}
```

### 3.2 全局异常处理器（详细分类）

```java
// 定义在 thesis-common，所有服务通过 @ComponentScan 自动加载
@RestControllerAdvice
@Slf4j
public class GlobalExceptionHandler {

    // 1. 业务异常（预期内的业务失败）
    @ExceptionHandler(BusinessException.class)
    public Result<Void> handleBusiness(BusinessException e, HttpServletRequest request) {
        log.warn("[业务异常] uri={}, code={}, message={}",
                request.getRequestURI(), e.getCode(), e.getMessage());
        return Result.fail(e.getCode(), e.getMessage());
    }

    // 2. JSR-303 参数校验失败
    @ExceptionHandler(MethodArgumentNotValidException.class)
    public Result<Void> handleValidation(MethodArgumentNotValidException e) {
        String message = e.getBindingResult().getFieldErrors().stream()
                .map(err -> err.getField() + "：" + err.getDefaultMessage())
                .collect(Collectors.joining("；"));
        log.warn("[参数校验失败] {}", message);
        return Result.fail(400, message);
    }

    // 3. 路径参数/类型转换失败
    @ExceptionHandler({MethodArgumentTypeMismatchException.class,
                       ConstraintViolationException.class})
    public Result<Void> handleTypeMismatch(Exception e) {
        log.warn("[参数类型错误] {}", e.getMessage());
        return Result.fail(400, "请求参数格式错误");
    }

    // 4. 数据库唯一约束冲突
    @ExceptionHandler(DuplicateKeyException.class)
    public Result<Void> handleDuplicateKey(DuplicateKeyException e) {
        log.warn("[唯一约束冲突] {}", e.getMessage());
        return Result.fail(409, "数据已存在，请勿重复提交");
    }

    // 5. Sa-Token 认证异常
    @ExceptionHandler(NotLoginException.class)
    public Result<Void> handleNotLogin(NotLoginException e) {
        log.warn("[未认证] type={}", e.getType());
        return Result.fail(401, "未认证，请先登录");
    }

    @ExceptionHandler(NotPermissionException.class)
    public Result<Void> handleNotPermission(NotPermissionException e) {
        log.warn("[无权限] permission={}, userId={}", e.getPermission(),
                tryGetCurrentUserId());
        return Result.fail(403, "无权限执行此操作");
    }

    // 6. Feign 调用异常
    @ExceptionHandler(FeignException.class)
    public Result<Void> handleFeign(FeignException e, HttpServletRequest request) {
        log.error("[Feign 调用失败] uri={}, status={}, message={}",
                request.getRequestURI(), e.status(), e.getMessage());
        if (e.status() == 503) {
            return Result.fail(503, "依赖服务暂时不可用，请稍后重试");
        }
        return Result.fail(500, "系统繁忙，请稍后重试");
    }

    // 7. 兜底异常（不可预期的系统错误）
    @ExceptionHandler(Exception.class)
    public Result<Void> handleUnknown(Exception e, HttpServletRequest request) {
        // 打印完整堆栈（ERROR 级别）
        log.error("[系统异常] uri={}, method={}",
                request.getRequestURI(), request.getMethod(), e);
        return Result.fail(500, "系统繁忙，请稍后重试");
    }

    private String tryGetCurrentUserId() {
        try { return String.valueOf(StpUtil.getLoginId()); }
        catch (Exception e) { return "anonymous"; }
    }
}
```

### 3.3 MQ 消费者异常处理

```java
// 消费者必须实现幂等 + 异常分类处理
@RocketMQMessageListener(
    topic = "thesis-paper-submit",
    consumerGroup = "thesis-notify-send-group"
)
@Slf4j
@Component
public class PaperSubmitConsumer implements RocketMQListener<PaperSubmitMessage> {

    @Override
    public void onMessage(PaperSubmitMessage message) {
        String msgId = message.getMsgId();
        try {
            // 1. 幂等检查（防止重复消费）
            if (isAlreadyProcessed(msgId)) {
                log.info("[MQ 幂等] 消息已处理，跳过 msgId={}", msgId);
                return;
            }

            // 2. 业务处理
            notifyService.sendReviewNotice(message.getPaperId(), message.getNodeType());

            // 3. 标记已处理（Redis SET 24h TTL）
            markAsProcessed(msgId);

        } catch (BusinessException e) {
            // 业务异常：记录日志，不重试（直接 ACK，避免死信堆积）
            log.warn("[MQ 业务异常] msgId={}, code={}, message={}", msgId, e.getCode(), e.getMessage());
        } catch (Exception e) {
            // 系统异常：记录日志，抛出让 RocketMQ 重试（最多 3 次后进死信队列）
            log.error("[MQ 消费失败] msgId={}, 将触发重试", msgId, e);
            throw new RuntimeException("消费失败，触发重试", e);
        }
    }
}
```

```java
// 在 Gateway 全局过滤器中记录接口耗时
// 超过阈值自动升级日志级别

@Component
public class ResponseTimeFilter implements GlobalFilter, Ordered {

    private static final long SLOW_REQUEST_THRESHOLD_MS = 500;  // 普通接口阈值
    private static final long AI_SLOW_THRESHOLD_MS = 10000;     // AI 接口阈值

    @Override
    public Mono<Void> filter(ServerWebExchange exchange, GatewayFilterChain chain) {
        long startTime = System.currentTimeMillis();
        return chain.filter(exchange).doFinally(signal -> {
            long duration = System.currentTimeMillis() - startTime;
            String path = exchange.getRequest().getPath().value();
            long threshold = path.contains("/ai/") ? AI_SLOW_THRESHOLD_MS : SLOW_REQUEST_THRESHOLD_MS;

            if (duration > threshold) {
                log.warn("[慢接口] path={}, method={}, duration={}ms, threshold={}ms",
                        path, exchange.getRequest().getMethod(), duration, threshold);
            } else {
                log.debug("[接口耗时] path={}, duration={}ms", path, duration);
            }
        });
    }
}
```

### 5.4 文件上传安全

```java
// 文件上传白名单（见 CLAUDE.md §10.2），后端必须二次校验（前端校验仅为体验）
public class FileSecurityValidator {

    private static final Map<String, Set<byte[]>> MAGIC_BYTES = Map.of(
        "pdf",  Set.of(new byte[]{0x25, 0x50, 0x44, 0x46}),         // %PDF
        "docx", Set.of(new byte[]{0x50, 0x4B, 0x03, 0x04}),         // ZIP 头（Office Open XML）
        "jpg",  Set.of(new byte[]{(byte)0xFF, (byte)0xD8, (byte)0xFF}),  // JPEG
        "png",  Set.of(new byte[]{(byte)0x89, 0x50, 0x4E, 0x47})    // PNG
    );

    private static final long MAX_FILE_SIZE_BYTES = 200 * 1024 * 1024L;  // 200MB

    public static void validate(MultipartFile file, Set<String> allowedTypes) {
        // 1. 文件大小校验
        if (file.getSize() > MAX_FILE_SIZE_BYTES) {
            throw new FileException(3002, "文件大小超出限制（最大 200MB）");
        }

        // 2. 扩展名白名单校验（大小写不敏感）
        String ext = FilenameUtils.getExtension(file.getOriginalFilename()).toLowerCase();
        if (!allowedTypes.contains(ext)) {
            throw new FileException(3001, "文件类型不支持，仅允许：" + allowedTypes);
        }

        // 3. 文件内容 Magic Bytes 校验（防止扩展名欺骗）
        try {
            byte[] header = new byte[8];
            file.getInputStream().read(header);
            if (!matchesMagicBytes(ext, header)) {
                throw new FileException(3001, "文件内容与扩展名不匹配");
            }
        } catch (IOException e) {
            throw new FileException(3003, "文件读取失败");
        }

        // 4. 文件名净化（防路径穿越）
        String safeFileName = FilenameUtils.getName(file.getOriginalFilename());
        if (safeFileName.contains("..") || safeFileName.contains("/")) {
            throw new FileException(3001, "文件名包含非法字符");
        }
    }
}
```

## 七、缓存使用规范

### 7.1 缓存操作模式（Cache-Aside）

```java
// 标准 Cache-Aside 实现（所有业务缓存统一遵守）

// 读操作
public PaperStatusVO getPaperStatus(Long paperId) {
    String cacheKey = "paper:status:" + paperId;

    // 1. 先查缓存
    PaperStatusVO cached = redisTemplate.opsForValue().get(cacheKey);
    if (cached != null) {
        return cached;
    }

    // 2. 缓存未命中，查数据库
    PaperStatusVO status = paperMapper.selectStatusById(paperId);
    if (status == null) {
        // 防缓存穿透：对 null 值使用布隆过滤器（见下方），不缓存 null
        return null;
    }

    // 3. 写缓存（设置 TTL）
    redisTemplate.opsForValue().set(cacheKey, status, 30, TimeUnit.MINUTES);
    return status;
}

// 写操作（先更新 DB，再删除缓存）
@Transactional(rollbackFor = Exception.class)
public void updatePaperStatus(Long paperId, NodeStatus status) {
    // 1. 更新数据库
    paperMapper.updateStatus(paperId, status);

    // 2. 删除缓存（让下次读时重新加载，保证一致性）
    // 注意：不是更新缓存，而是删除（防止并发更新导致缓存值与 DB 不一致）
    redisTemplate.delete("paper:status:" + paperId);

    // 3. 操作日志（同事务）
    saveOperationLog(...);
}

// 缓存穿透防护（布隆过滤器）
@Component
public class PaperBloomFilter {

    private final RBloomFilter<Long> bloomFilter;

    public PaperBloomFilter(RedissonClient redisson) {
        this.bloomFilter = redisson.getBloomFilter("paper:bloom");
        this.bloomFilter.tryInit(1_000_000L, 0.03);  // 100万容量，3% 误判率
    }

    // 论文创建时加入布隆过滤器
    public void add(Long paperId) { bloomFilter.add(paperId); }

    // 查询前先检查（若布隆过滤器说不存在，直接返回 null，不查 DB）
    public boolean mightExist(Long paperId) { return bloomFilter.contains(paperId); }
}
```

### 7.3 分布式锁使用规范

```java
// 使用 Redisson，禁止使用 SETNX 手写分布式锁（存在非原子操作风险）

// 标准分布式锁使用模式
RLock lock = redissonClient.getLock(CacheKeyConstants.topicLock(batchId, topicHash));
boolean locked = false;
try {
    // tryLock：等待 0ms（立即失败），锁持有 30s（防止死锁）
    locked = lock.tryLock(0, 30, TimeUnit.SECONDS);
    if (!locked) {
        throw PaperFlowException.topicAlreadyChosen();
    }
    // 双重校验：获取锁后再次检查 DB（防止锁获取时间窗口内其他事务已写入）
    if (topicMapper.existsByHash(batchId, topicHash)) {
        throw PaperFlowException.topicAlreadyChosen();
    }
    // 执行业务操作
    topicMapper.insert(topic);
} finally {
    // 必须在 finally 中释放锁，且只有当前线程持有锁时才释放
    if (locked && lock.isHeldByCurrentThread()) {
        lock.unlock();
    }
}
```

### 12.1 集合与流操作规范

```java
// 规范 1：初始化集合时指定容量（避免频繁扩容）
List<PaperVO> paperList = new ArrayList<>(papers.size());
Map<Long, Teacher> teacherMap = new HashMap<>(teachers.size() * 4 / 3 + 1);

// 规范 2：Stream 操作链避免多次遍历
// 错误写法（两次遍历）：
List<Long> teacherIds = papers.stream().map(Paper::getTeacherId).collect(toList());
Set<Long> uniqueIds = new HashSet<>(teacherIds);

// 正确写法（一次遍历）：
Set<Long> teacherIds = papers.stream().map(Paper::getTeacherId).collect(toSet());

// 规范 3：禁止在 Stream 中嵌套数据库查询
// 错误写法（每次迭代查 DB）：
papers.stream().map(p -> {
    Teacher t = teacherMapper.selectById(p.getTeacherId());  // 禁止！
    return buildVO(p, t);
}).collect(toList());

// 规范 4：大量数据处理使用分页而非全量加载
// 错误写法（全量加载到内存）：
List<Paper> allPapers = paperMapper.selectAll();  // 可能 10 万条！

// 正确写法（分批处理）：
int pageNum = 1;
List<Paper> batch;
do {
    batch = paperMapper.selectPage(new Page<>(pageNum++, 500), wrapper).getRecords();
    processBatch(batch);
} while (batch.size() == 500);
```

### 12.2 异步处理规范

```java
// 非核心链路操作使用异步执行（避免阻塞主流程）
// 适合异步：操作日志写入、通知发送、统计刷新、AI 评议触发

// 线程池配置（各服务独立配置，避免共用导致资源争抢）
@Configuration
@EnableAsync
public class AsyncConfig {

    @Bean("logExecutor")
    public Executor logExecutor() {
        ThreadPoolTaskExecutor executor = new ThreadPoolTaskExecutor();
        executor.setCorePoolSize(2);
        executor.setMaxPoolSize(5);
        executor.setQueueCapacity(500);
        executor.setThreadNamePrefix("log-async-");
        executor.setRejectedExecutionHandler(new CallerRunsPolicy());  // 队列满时退化为同步
        executor.initialize();
        return executor;
    }

    @Bean("notifyExecutor")
    public Executor notifyExecutor() {
        // 通知执行器（独立线程池）
        ThreadPoolTaskExecutor executor = new ThreadPoolTaskExecutor();
        executor.setCorePoolSize(4);
        executor.setMaxPoolSize(10);
        executor.setQueueCapacity(200);
        executor.setThreadNamePrefix("notify-async-");
        executor.setRejectedExecutionHandler(new CallerRunsPolicy());
        executor.initialize();
        return executor;
    }
}

// 使用虚拟线程（JDK 21 特性，适合 I/O 密集型异步任务）
// 在 application.yml 中启用：
// spring.threads.virtual.enabled=true
```

## 附录 B：代码评审检查清单

PR 提交者在提交前必须自检，Reviewer 在审核时核对：

**架构合规**
- [ ] Controller 无业务逻辑，只调用 Service
- [ ] Service 不直接注入其他 Service 实现（跨模块用 Feign/MQ）
- [ ] `@Transactional` 只在 Service 实现层，有 `rollbackFor = Exception.class`

- [ ] 无循环内 DB 查询（N+1 问题）
- [ ] 列表查询未 SELECT 大字段（paper_content 等）
- [ ] 新增查询字段有对应索引（EXPLAIN 验证）
- [ ] 批量写入使用 `saveBatch(list, 500)`，未一次性提交超大事务

- [ ] 业务异常使用 `BusinessException` 或子类，无裸 `RuntimeException`

- [ ] 所有缓存操作有 TTL（选题锁除外）
